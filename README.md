# 📊 Data Analysis Dashboard - MS Excel

This project showcases a **professional data analysis dashboard built using Microsoft Excel**. It is designed to help visualize, analyze, and interpret business data efficiently. The dashboard presents insights in an interactive and visually engaging way to support better decision-making.

## ✅ Key Features

- 📈 **Interactive Dashboard** with slicers and dynamic charts  
- 📊 **Pivot Tables** and **Pivot Charts** for detailed data breakdown  
- 💹 **KPI Metrics** like Total Sales, Profit, Quantity Sold, and Average Price  
- 📍 Region-wise and Category-wise performance tracking  
- 🎯 Clean, user-friendly interface for executives and analysts  

## 🛠 Tools & Technologies

- Microsoft Excel  
- Data Cleaning  
- Pivot Table & Charts  
- Conditional Formatting  
- Slicers for interactivity  

## 📁 Files Included

- Excel workbook (.xlsx) with the complete dashboard  
- Raw data sheets  
- Visualizations on separate dashboard sheets
